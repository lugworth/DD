# Overprint

A generative **riso press**. Every impression is 1–4 *plates*, each one
generated by a different exotic algorithm, then overprinted in
misregistered spot inks through real halftone screens onto paper stock —
grain, registration crosses, colour bar and all.

Thirteenth sibling in the tools family — same shell, same rack UX. Open
`index.html` in a browser. No build step, no dependencies — single
self-contained file styled with the digidelic design system.

## Plate engines

The point of this tool is the engine list: eight generative algorithms
that appear nowhere else in the family, each producing an ink-coverage
plate rather than a finished picture.

| Engine | Algorithm | What it looks like |
|---|---|---|
| `physarum` | Slime-mould agents sense a pheromone trail, steer toward the strongest reading, deposit, and the trail diffuses + decays | Vein and network structures, transport webs |
| `quasicrystal` | Sum of N plane waves at aperiodic angles | Non-repeating interference, moiré, oil-slick banding |
| `aggregation` | Diffusion-limited aggregation — random walkers freeze on contact | Frost, corrosion, dendrites, lightning |
| `contour` | Marching squares over domain-warped fbm, stacked at many thresholds | Topographic line plates |
| `superformula` | Gielis superformula rosettes | Stars, gears, petals, lozenges from one equation |
| `pixel sort` | Rows cut into runs by a noise mask, each run re-ordered by luminance | Datamosh streaks and glitch bands |
| `tile collapse` | Adjacency-constrained tile placement (a deliberately small WFC) — every tile's edge connectors must match its neighbours | Continuous circuitry, CAD sheets, pipework |
| `type ring` | Concentric rings of type set letter-by-letter around arcs | Radial listings, record-label centre labels |

The **Engine pool** control decides which engines are eligible:
`Bio` (physarum · aggregation · contour), `Wave` (quasicrystal ·
superformula · pixel sort), `Tech` (tile collapse · type ring), or
`Auto` for all eight.

## How the press works

Engines never deal in colour — they paint opaque coverage on a
transparent plate raster. The press then re-screens that coverage as a
rotated halftone lattice per ink, at that ink's **own screen angle**
(15° / 75° / 0° / 45°, the way a shop offsets screens to dodge moiré),
with a per-plate misregistration offset. Dots are drawn vectorially at
output resolution, so a 2× export is genuinely crisp even though the
plate raster itself is modest.

Baking plates (running the engines) and pressing them (screening,
misregistering, inking) are separate stages: press controls recomposite
instantly from cached plates, while structural controls re-bake — and
re-bakes coalesce during a slider drag, since a physarum plate at full
growth is a few hundred milliseconds of simulation.

## Parameter rack

| Section | Control | Effect |
|---|---|---|
| Seed | Hex readout + `⟳ Reseed` | Deterministic engine picks and plate content. Click the hex to copy a shareable link |
| | Plate chips | One row per plate — click any chip to re-roll just that plate onto a new engine |
| Plates | Plate count | 1–4 separations |
| | Engine pool | Which engine family is eligible |
| | Density | Agent/particle/element counts, contour levels, tile grid |
| | Complexity | Wave count, turn rates, tile intricacy, warp depth |
| | Scale | Feature size — sensor distance, frequency, rosette radius |
| | Growth | Simulation iterations for the time-based engines |
| Press | Misregistration | Plate offset and screen-angle jitter |
| | Screen freq | Halftone lattice frequency (coarse poster ↔ fine litho) |
| | Ink density | Per-plate opacity |
| | Paper grain | Stock tooth |
| | Margin | Trim inset |
| | Trim marks | Registration crosses, colour bar, seed slug |
| Style | Ink set | `Riso` (fluoro pink/blue/yellow/black on cream) · `CMYK` · `Digidelic` (neon on void, screen blend) · `Mono` |
| | Format | 1:1 · 4:5 · 2:3 poster |

`space` = new press run, `e` = export PNG, `Ctrl+Z` / `Ctrl+Shift+Z` =
undo/redo. **Click the sheet** to re-roll whichever plate is inked
heaviest under the pointer.

## Export

`▶ Export PNG` re-presses at 2× (2160px wide) and downloads
`digidelic-overprint-<seed>.png`. Because the halftone lattice is
recomputed at the export resolution, dot edges are vector-crisp rather
than upscaled.
