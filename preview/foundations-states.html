Documenting them once here — rather than re-deriving them on each component page — is what keeps a button and a text input feeling like the same machine. Read a column to learn a state; read a row to learn a component.

// the seven laws
Rest
Hairline border, 1px white @12%. No fill unless the component is a primary action. This is the quietest the system gets.
Hover
Translate −2px, −2px with a 3px hard offset shadow. Never a soft glow, never a blur. The element physically lifts off the void — a shadow with a hard edge reads as a printed layer, not a light source.
Focus
2px solid #2d6cff outline at 1px offset — flipped to white on cobalt fills. Always distinct from hover so mouse and keyboard users can tell them apart. Never removed.
Active
Snap back to translate(0,0), shadow gone. Fills darken one step. Press should feel like the element hits the page.
Disabled
Fill drops to #1a1a18, text to rgba(255,255,255,.28), border to 10%. Exempt from contrast minimums, but never so faint it reads as absent.
Loading
Retain the element's footprint — replace content with a spinner or skeleton bars, never collapse the box. Layout must not shift when the data lands.
Error
Border flips to #ff0066 and a glyph joins the message. Color never carries the error alone.
