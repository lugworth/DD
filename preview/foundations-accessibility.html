Accessibility

digidelic is a neon-on-void system, which makes most of its pairings dramatically over-threshold — and makes the few failures easy to miss. Every ratio below is computed, not estimated. Brutalism's stark palette is an accessibility asset; the thick borders and chunky blocks the style already demands are exactly what focus rings and target sizes need.

// 01 · verified contrast pairings

WCAG 2.2 AA: 4.5:1 body text · 3:1 large text (18pt / 14pt bold+) and non-text UI (borders, focus rings, meaningful icons). Ratios computed against the stated background — recompute if you place a color on anything else.

Cobalt is the only color in the system that works in every direction. 4.70:1 as text on black, 4.70:1 with black label text on it, 4.47:1 with white — so a cobalt fill takes either text color and a cobalt rule reads on the void. That is why it carries the primary action and the focus ring. The margins are far thinner than the retired acid hero's, though: cobalt is not a large-text exemption color, and it must never drop below 14px bold when reversed out in white.

// 02 · muted text floor

The system leans on low-alpha white for secondary labels. Below rgba(255,255,255,.55) that text stops passing AA on black. Treat .55 as the floor for anything readable; reserve lower alphas for non-informational rules and dividers.

// 03 · focus ring

A 2px hard cobalt ring at 1px offset, never removed, always distinct from hover. Cobalt reads 4.70:1 against black and clears 3:1 against every surface in the system — except cobalt itself, where the ring flips to white. Focus is a design feature here, not an apology: the thick-border vocabulary the brand already speaks is exactly what WCAG 2.4.11 wants.

// 04 · target size

WCAG 2.5.8 sets a 24×24 CSS px minimum; 44×44 is the mobile target this system ships. Brutalism's chunky controls make this free — the failure mode is icon-only glyphs shrunk to fit a dense row.

// 05 · motion policy

The glitch and psychedelia layers loop indefinitely by design. WCAG 2.2.2 requires a way to stop looping motion, and 2.3.3 requires honoring system preference. Both layers collapse under prefers-reduced-motion: reduce — animations resolve to their rest frame rather than disappearing, so nothing shifts layout. Never ship an auto-looping decorative layer without that guard.

prefers-reduced-motion
All gl-* and psy-* animations → none. Static rest frame retained.

// 07 · rules

Do

  • Pair status color with a glyph — ▶ nominal, ✕ critical. Color alone never carries meaning.
  • Use semantic elements. A <button> is focusable and Enter-activatable for free.
  • Keep the focus ring distinct from hover — hover translates, focus rings.
  • Recompute contrast whenever a color moves to a new surface.
  • Let the brutalist border weight do the accessibility work.

Don't

  • Treat cobalt as a hazard or warning signal — that is --orange. Cobalt means primary, not danger.
  • Drop informational label text below rgba(255,255,255,.55).
  • Remove outline without shipping a replacement.
  • Ship a looping glitch layer with no reduced-motion branch.
  • Shrink an icon-only control below 24×24 to fit a dense row.
  • Rely on the cobalt focus ring against a cobalt fill — flip it to white.
